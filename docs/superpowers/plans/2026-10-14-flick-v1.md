# Flick v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu-bar macOS app that snaps the window under the pointer to a 2×2 grid slot on a two-finger titlebar swipe, and fills or restores it on a titlebar pinch, with a live preview overlay.

**Architecture:** One SwiftPM package. `FlickCore` is a pure-Swift library (no AppKit / ApplicationServices) holding all logic: geometry, layout, direction classification, the gesture state machine and the controller. It talks to the OS only through `@MainActor` protocols. `Flick` is the executable: thin adapters around `CGEventTap`, Accessibility (`AXUIElement`), `NSScreen`, an `NSPanel` overlay and an `NSStatusItem` menu.

**Tech Stack:** Swift 6 (Xcode toolchain), SwiftPM, swift-testing, AppKit, ApplicationServices; Nix flake dev shell (go-task, swiftlint, pre-commit); Task as task runner.

**Spec:** `docs/superpowers/specs/2026-10-14-flick-v1-design.md` (design drivers: `docs/design/gesture-map.png`, `docs/design/live-preview-menu-bar.png`)

## Global Constraints

- `swift-tools-version: 6.0`, Swift 6 language mode, deployment target macOS 14 (`.macOS(.v14)`).
- `FlickCore` imports nothing but `Foundation`. Everything touching AppKit, ApplicationServices or CoreGraphics lives in `Sources/Flick/`.
- No private frameworks or private API.
- Constants (copied from the spec): swipe threshold **40 pt**, pinch threshold **±0.15** cumulative magnification, titlebar zone **top 40 pt**, gap **8 pt**, overlay **12 pt** corner radius, **2 pt** border, accent **#2F6BFF** at **20 %** fill.
- Coordinates in `FlickCore` are global, top-left origin, y down (`GlobalPoint`, `GlobalRect`). AppKit rects are converted with `GlobalRect.flipped(primaryHeight:)`.
- Do not name types `Point`, `Rect` or `WindowRef`. They clash with MacTypes / Carbon types that ApplicationServices imports and cause "ambiguous for type lookup" errors.
- Bundle identifier `local.personal.flick`, executable and app name `Flick`.
- Tests use swift-testing (`import Testing`, `@Test`, `#expect`), not XCTest.
- `task lint` (swiftlint strict + `swift format lint --strict`) and `task test` must pass at the end of every task.
- Git: the user works on `main` for this project. **Never run `git commit` yourself.** At each commit step, stage the listed files and hand the user the `gitcs '<message>'` command (their signing alias; it needs a hardware token). Conventional Commits. Never bypass signing.

## Review Focus

Uncovered input classes a person will hit, most likely first. Each line names where it gets pinned:

1. **A gesture that starts off a titlebar** (window body, desktop, Dock, menu bar, Flick's own overlay) must reach the app untouched, including its momentum events. Pinned by `swipeOffTitlebarPassesThroughIncludingMomentum` and `pinchOffTitlebarPassesThrough` (Task 5); the adapter side (subrole `AXStandardWindow`, own PID ignored) is in the manual checklist (Task 9).
2. **Classic (non-natural) scrolling** must still map finger direction correctly: ↖ means top-left either way. Pinned by `classicScrollingDeltasAreNegated` (Task 4) and `classicScrollingIsNormalisedToFingerDirection` (Task 5), and confirmed against real hardware in the spike (Task 1).
3. **Second display / non-zero origins** (a display above or left of the primary, so negative coordinates; menu-bar offset). Pinned by `flipsSecondaryDisplayAbovePrimaryToNegativeY` (Task 2) and `worksOnASecondaryDisplayWithNegativeOrigin` (Task 3).
4. **Restore with nothing to restore** (never snapped, second pinch-in, failed move, window closed mid-gesture) must do nothing and leave no preview behind. Pinned by `restoreWithoutHistoryDoesNothing`, `secondRestoreDoesNothing`, `failedMoveIsNotRecorded` and `windowThatDisappearedIsIgnored` (Task 6).
5. **Touches without a real gesture** (fingers rest then lift, system-cancelled gestures, scroll events arriving mid-pinch, pausing mid-gesture) must not snap anything or leave the overlay up. Pinned by `touchWithoutMovementIsIgnored`, `systemCancelledSwipeHidesPreview`, `scrollEventsDuringAPinchPassThroughAndDoNotDisturbIt` and `pausingMidGestureLetsTheGestureFinish` (Task 5).

```swift
// Throwaway spike: logs trackpad scroll and gesture events seen by a session event tap.
// Run from a terminal that has Accessibility access:  swift EventTapSpike.swift [--swallow-pinch]
import AppKit

let swallowPinch = CommandLine.arguments.contains("--swallow-pinch")

func describe(_ phase: NSEvent.Phase) -> String {
    let names: [(NSEvent.Phase, String)] = [
        (.mayBegin, "mayBegin"), (.began, "began"), (.changed, "changed"),
        (.stationary, "stationary"), (.ended, "ended"), (.cancelled, "cancelled"),
    ]
    let matched = names.filter { phase.contains($0.0) }.map(\.1)
    return matched.isEmpty ? "-" : matched.joined(separator: "|")
}

let callback: CGEventTapCallBack = { _, type, event, _ in
    guard let ns = NSEvent(cgEvent: event) else { return Unmanaged.passUnretained(event) }
    let loc = event.location
    switch ns.type {
    case .scrollWheel where ns.hasPreciseScrollingDeltas:
        print(
            String(
                format: "scroll   cg=%2d phase=%-9@ momentum=%-9@ dX=%7.2f dY=%7.2f inverted=%@ at (%.0f, %.0f)",
                type.rawValue, describe(ns.phase), describe(ns.momentumPhase), ns.scrollingDeltaX,
                ns.scrollingDeltaY, ns.isDirectionInvertedFromDevice ? "yes" : "no", loc.x, loc.y))
    case .magnify:
        print(
            String(
                format: "magnify  cg=%2d phase=%-9@ magnification=%+.3f at (%.0f, %.0f)%@",
                type.rawValue, describe(ns.phase), ns.magnification, loc.x, loc.y,
                swallowPinch ? "  [swallowed]" : ""))
        if swallowPinch { return nil }
    default:
        break
    }
    return Unmanaged.passUnretained(event)
}

let mask = (CGEventMask(1) << CGEventType.scrollWheel.rawValue) | (CGEventMask(1) << 29) | (CGEventMask(1) << 30)
guard
    let port = CGEvent.tapCreate(
        tap: .cgSessionEventTap, place: .headInsertEventTap, options: .defaultTap,
        eventsOfInterest: mask, callback: callback, userInfo: nil)
else {
    print("tapCreate failed: give this terminal app Accessibility access and retry")
    exit(1)
}
CFRunLoopAddSource(CFRunLoopGetMain(), CFMachPortCreateRunLoopSource(nil, port, 0), .commonModes)
CGEvent.tapEnable(tap: port, enable: true)
print("Listening. Swipe and pinch on the trackpad; Ctrl-C to stop.")
CFRunLoopRun()
```

`Sources/FlickCore/Geometry.swift`:

```swift
/// A point in Flick's global coordinate space: origin at the top-left corner of the
/// primary display, y grows downwards. CGEvent locations and Accessibility frames use it.
public struct GlobalPoint: Equatable, Sendable {
    public var x: Double
    public var y: Double

    public init(x: Double, y: Double) {
        self.x = x
        self.y = y
    }
}

/// An axis-aligned rectangle in Flick's global (top-left origin) coordinate space.
public struct GlobalRect: Equatable, Sendable {
    public var x: Double
    public var y: Double
    public var width: Double
    public var height: Double

    public init(x: Double, y: Double, width: Double, height: Double) {
        self.x = x
        self.y = y
        self.width = width
        self.height = height
    }

    public var minX: Double { x }
    public var minY: Double { y }
    public var maxX: Double { x + width }
    public var maxY: Double { y + height }
    public var midX: Double { x + width / 2 }

    /// Half-open containment: the left and top edges are inside, the right and bottom are not.
    public func contains(_ point: GlobalPoint) -> Bool {
        point.x >= minX && point.x < maxX && point.y >= minY && point.y < maxY
    }

    /// Mirrors the rect between AppKit's bottom-left-origin space (NSScreen, NSWindow) and
    /// Flick's top-left-origin space. Applying it twice returns the original rect.
    /// - Parameter primaryHeight: height of the primary display (`NSScreen.screens[0]`).
    public func flipped(primaryHeight: Double) -> GlobalRect {
        GlobalRect(x: x, y: primaryHeight - y - height, width: width, height: height)
    }
}
```

```swift
/// Turns a slot into a window frame inside a screen's visible frame.
public enum LayoutEngine {
    /// Gap in points between slots and against the visible-frame edges.
    public static let defaultGap: Double = 8

    public static func frame(for slot: Slot, in visible: GlobalRect, gap: Double = defaultGap) -> GlobalRect {
        let fullWidth = (visible.width - 2 * gap).rounded(.down)
        let fullHeight = (visible.height - 2 * gap).rounded(.down)
        let halfWidth = ((visible.width - 3 * gap) / 2).rounded(.down)
        let halfHeight = ((visible.height - 3 * gap) / 2).rounded(.down)

        let left = (visible.minX + gap).rounded()
        let top = (visible.minY + gap).rounded()
        // Right column and bottom row are anchored to the far edges so the outer gap stays exact.
        let right = (visible.maxX - gap).rounded() - halfWidth
        let bottom = (visible.maxY - gap).rounded() - halfHeight

        switch slot {
        case .leftHalf: return GlobalRect(x: left, y: top, width: halfWidth, height: fullHeight)
        case .rightHalf: return GlobalRect(x: right, y: top, width: halfWidth, height: fullHeight)
        case .topHalf: return GlobalRect(x: left, y: top, width: fullWidth, height: halfHeight)
        case .bottomHalf: return GlobalRect(x: left, y: bottom, width: fullWidth, height: halfHeight)
        case .topLeft: return GlobalRect(x: left, y: top, width: halfWidth, height: halfHeight)
        case .topRight: return GlobalRect(x: right, y: top, width: halfWidth, height: halfHeight)
        case .bottomLeft: return GlobalRect(x: left, y: bottom, width: halfWidth, height: halfHeight)
        case .bottomRight: return GlobalRect(x: right, y: bottom, width: halfWidth, height: halfHeight)
        case .fill: return GlobalRect(x: left, y: top, width: fullWidth, height: fullHeight)
        }
    }
}
```

Gap maths (from the spec): halves are `(visible − 3·gap) / 2`, full spans are `visible − 2·gap`, and everything is rounded to whole points. The right column and bottom row are anchored to the far edge, so with an odd leftover the middle gap is 9 pt instead of 8. The tests allow exactly that.

```swift
import Foundation

/// Maps a finger translation to one of the 8 swipe slots.
public enum DirectionClassifier {
    /// Below this distance (points) a swipe has no direction yet.
    public static let minimumDistance: Double = 40

    // Sector 0 is "right", then clockwise in screen orientation (y grows downwards).
    private static let sectors: [Slot] = [
        .rightHalf, .bottomRight, .bottomHalf, .bottomLeft,
        .leftHalf, .topLeft, .topHalf, .topRight,
    ]

    /// - Parameters:
    ///   - dx: finger movement to the right (negative = left), in points.
    ///   - dy: finger movement downwards (negative = up), in points.
    public static func slot(dx: Double, dy: Double, minimumDistance: Double = minimumDistance) -> Slot? {
        guard (dx * dx + dy * dy).squareRoot() >= minimumDistance else { return nil }
        var degrees = atan2(dy, dx) * 180 / .pi
        if degrees < 0 { degrees += 360 }
        let sector = Int(((degrees + 22.5) / 45).rounded(.down)) % 8
        return sectors[sector]
    }

    /// Converts AppKit scrolling deltas into finger movement in screen orientation.
    /// With natural scrolling (`invertedFromDevice == true`) the deltas already follow the
    /// fingers; with classic scrolling they point the opposite way.
    public static func fingerDelta(
        scrollingDeltaX: Double,
        scrollingDeltaY: Double,
        invertedFromDevice: Bool
    ) -> (dx: Double, dy: Double) {
        let sign: Double = invertedFromDevice ? 1 : -1
        return (sign * scrollingDeltaX, sign * scrollingDeltaY)
    }
}
```

```swift
/// Finds the window whose titlebar is under a point.
@MainActor
public protocol TitlebarProbe: AnyObject {
    func window(atTitlebar point: GlobalPoint) -> WindowHandle?
}

/// The window a claimed gesture acts on, and where the pointer was when it started.
public struct GestureContext: Equatable {
    public let window: WindowHandle
    public let pointer: GlobalPoint

    public init(window: WindowHandle, pointer: GlobalPoint) {
        self.window = window
        self.pointer = pointer
    }
}

public enum GestureUpdate: Equatable {
    /// The target changed while the fingers are still down. `nil` means "no target right now".
    case preview(GestureContext, Target?)
    /// The fingers lifted with a target.
    case commit(GestureContext, Target)
    /// The gesture ended without a target, or the system cancelled it.
    case cancel
}

/// Decides which trackpad gestures belong to Flick and turns them into `GestureUpdate`s.
@MainActor
public final class GestureRecognizer {
    /// Cumulative magnification needed before a pinch has a target.
    public static let pinchThreshold = 0.15

    /// While paused, new gestures are not claimed. A gesture already in progress finishes.
    public var isPaused = false

    private enum State {
        case idle
        case swiping(GestureContext, dx: Double, dy: Double, target: Target?)
        case pinching(GestureContext, scale: Double, target: Target?)
        case swallowingMomentum
    }

    private let probe: TitlebarProbe
    private let onUpdate: (GestureUpdate) -> Void
    private var state: State = .idle

    public init(probe: TitlebarProbe, onUpdate: @escaping (GestureUpdate) -> Void) {
        self.probe = probe
        self.onUpdate = onUpdate
    }

    public func handle(_ event: InputEvent) -> EventDecision {
        switch event {
        case let .scroll(phase, deltaX, deltaY, inverted, location):
            let finger = DirectionClassifier.fingerDelta(
                scrollingDeltaX: deltaX, scrollingDeltaY: deltaY, invertedFromDevice: inverted)
            return handleScroll(phase: phase, dx: finger.dx, dy: finger.dy, location: location)
        case let .momentum(phase):
            return handleMomentum(phase: phase)
        case let .magnify(phase, magnification, location):
            return handleMagnify(phase: phase, magnification: magnification, location: location)
        }
    }

    private func handleScroll(phase: GesturePhase, dx: Double, dy: Double, location: GlobalPoint) -> EventDecision {
        switch (state, phase) {
        case (.pinching, _), (_, .mayBegin):
            return .passThrough
        case (_, .began):
            guard let context = claim(at: location) else {
                state = .idle
                return .passThrough
            }
            state = .swiping(context, dx: 0, dy: 0, target: nil)
            return accumulateSwipe(dx: dx, dy: dy)
        case (.swiping, .changed):
            return accumulateSwipe(dx: dx, dy: dy)
        case let (.swiping(context, _, _, target), .ended):
            finish(context, target: target)
            state = .swallowingMomentum
            return .swallow
        case (.swiping, .cancelled):
            onUpdate(.cancel)
            state = .idle
            return .swallow
        default:
            return .passThrough
        }
    }

    private func accumulateSwipe(dx: Double, dy: Double) -> EventDecision {
        guard case let .swiping(context, oldX, oldY, oldTarget) = state else { return .passThrough }
        let newX = oldX + dx
        let newY = oldY + dy
        let target = DirectionClassifier.slot(dx: newX, dy: newY).map(Target.slot)
        state = .swiping(context, dx: newX, dy: newY, target: target)
        if target != oldTarget {
            onUpdate(.preview(context, target))
        }
        return .swallow
    }

    private func handleMomentum(phase: GesturePhase) -> EventDecision {
        guard case .swallowingMomentum = state else { return .passThrough }
        if phase == .ended || phase == .cancelled {
            state = .idle
        }
        return .swallow
    }

    private func handleMagnify(phase: GesturePhase, magnification: Double, location: GlobalPoint) -> EventDecision {
        switch (state, phase) {
        case (.swiping, _), (_, .mayBegin):
            return .passThrough
        case (_, .began):
            guard let context = claim(at: location) else {
                state = .idle
                return .passThrough
            }
            state = .pinching(context, scale: 0, target: nil)
            return accumulatePinch(magnification)
        case (.pinching, .changed):
            return accumulatePinch(magnification)
        case let (.pinching(context, _, target), .ended):
            finish(context, target: target)
            state = .idle
            return .swallow
        case (.pinching, .cancelled):
            onUpdate(.cancel)
            state = .idle
            return .swallow
        default:
            return .passThrough
        }
    }

    private func accumulatePinch(_ magnification: Double) -> EventDecision {
        guard case let .pinching(context, oldScale, oldTarget) = state else { return .passThrough }
        let scale = oldScale + magnification
        let target: Target?
        if scale > Self.pinchThreshold {
            target = .slot(.fill)
        } else if scale < -Self.pinchThreshold {
            target = .restore
        } else {
            target = nil
        }
        state = .pinching(context, scale: scale, target: target)
        if target != oldTarget {
            onUpdate(.preview(context, target))
        }
        return .swallow
    }

    private func claim(at location: GlobalPoint) -> GestureContext? {
        guard !isPaused, let window = probe.window(atTitlebar: location) else { return nil }
        return GestureContext(window: window, pointer: location)
    }

    private func finish(_ context: GestureContext, target: Target?) {
        if let target {
            onUpdate(.commit(context, target))
        } else {
            onUpdate(.cancel)
        }
    }
}
```

```swift
/// Remembers, per window, the frame it had before Flick last moved it.
public struct FrameHistory {
    private var frames: [WindowHandle: GlobalRect] = [:]

    public init() {}

    public mutating func record(_ frame: GlobalRect, for window: WindowHandle) {
        frames[window] = frame
    }

    public func peek(for window: WindowHandle) -> GlobalRect? {
        frames[window]
    }

    public mutating func take(for window: WindowHandle) -> GlobalRect? {
        frames.removeValue(forKey: window)
    }
}
```

```swift
/// Reads and moves windows.
@MainActor
public protocol WindowAccess: AnyObject {
    func frame(of window: WindowHandle) -> GlobalRect?
    /// Returns `false` if the window could not be moved at all.
    func setFrame(_ frame: GlobalRect, of window: WindowHandle) -> Bool
}

/// Knows the screens.
@MainActor
public protocol ScreenProvider: AnyObject {
    /// Visible frame (no menu bar, no Dock) of the screen containing `point`.
    func visibleFrame(containing point: GlobalPoint) -> GlobalRect?
}

/// Shows the target frame while a gesture is in progress.
@MainActor
public protocol PreviewPresenter: AnyObject {
    func show(_ frame: GlobalRect)
    func hide()
}

/// Turns gesture updates into previews and window moves.
@MainActor
public final class FlickController {
    private let windows: WindowAccess
    private let screens: ScreenProvider
    private let preview: PreviewPresenter
    private let gap: Double
    private var history = FrameHistory()

    public init(
        windows: WindowAccess,
        screens: ScreenProvider,
        preview: PreviewPresenter,
        gap: Double = LayoutEngine.defaultGap
    ) {
        self.windows = windows
        self.screens = screens
        self.preview = preview
        self.gap = gap
    }

    public func handle(_ update: GestureUpdate) {
        switch update {
        case let .preview(context, target):
            if let target, let frame = frame(for: target, context: context) {
                preview.show(frame)
            } else {
                preview.hide()
            }
        case let .commit(context, target):
            preview.hide()
            commit(target, context: context)
        case .cancel:
            preview.hide()
        }
    }

    private func frame(for target: Target, context: GestureContext) -> GlobalRect? {
        switch target {
        case let .slot(slot):
            guard let visible = screens.visibleFrame(containing: context.pointer) else { return nil }
            return LayoutEngine.frame(for: slot, in: visible, gap: gap)
        case .restore:
            return history.peek(for: context.window)
        }
    }

    private func commit(_ target: Target, context: GestureContext) {
        let window = context.window
        switch target {
        case .slot:
            guard let current = windows.frame(of: window),
                let next = frame(for: target, context: context),
                windows.setFrame(next, of: window)
            else { return }
            history.record(current, for: window)
        case .restore:
            guard let previous = history.take(for: window) else { return }
            _ = windows.setFrame(previous, of: window)
        }
    }
}
```

```swift
import ApplicationServices
import FlickCore

/// Small typed wrappers around the Accessibility C API.
enum Accessibility {
    static func isTrusted(prompt: Bool) -> Bool {
        // String literal instead of kAXTrustedCheckOptionPrompt: the global is not
        // concurrency-safe under Swift 6 strict checking.
        let options = ["AXTrustedCheckOptionPrompt": prompt] as CFDictionary
        return AXIsProcessTrustedWithOptions(options)
    }

    static func string(_ element: AXUIElement, _ attribute: String) -> String? {
        copy(element, attribute) as? String
    }

    static func element(_ element: AXUIElement, _ attribute: String) -> AXUIElement? {
        guard let value = copy(element, attribute), CFGetTypeID(value) == AXUIElementGetTypeID() else {
            return nil
        }
        return (value as! AXUIElement)  // swiftlint:disable:this force_cast
    }

    static func frame(of element: AXUIElement) -> GlobalRect? {
        var position = CGPoint.zero
        var size = CGSize.zero
        guard let positionValue = axValue(element, kAXPositionAttribute),
            let sizeValue = axValue(element, kAXSizeAttribute),
            AXValueGetValue(positionValue, .cgPoint, &position),
            AXValueGetValue(sizeValue, .cgSize, &size)
        else { return nil }
        return GlobalRect(x: position.x, y: position.y, width: size.width, height: size.height)
    }

    @discardableResult
    static func setPosition(_ element: AXUIElement, x: Double, y: Double) -> Bool {
        var point = CGPoint(x: x, y: y)
        guard let value = AXValueCreate(.cgPoint, &point) else { return false }
        return AXUIElementSetAttributeValue(element, kAXPositionAttribute as CFString, value) == .success
    }

    @discardableResult
    static func setSize(_ element: AXUIElement, width: Double, height: Double) -> Bool {
        var size = CGSize(width: width, height: height)
        guard let value = AXValueCreate(.cgSize, &size) else { return false }
        return AXUIElementSetAttributeValue(element, kAXSizeAttribute as CFString, value) == .success
    }

    private static func copy(_ element: AXUIElement, _ attribute: String) -> CFTypeRef? {
        var value: CFTypeRef?
        guard AXUIElementCopyAttributeValue(element, attribute as CFString, &value) == .success else { return nil }
        return value
    }

    private static func axValue(_ element: AXUIElement, _ attribute: String) -> AXValue? {
        guard let value = copy(element, attribute), CFGetTypeID(value) == AXValueGetTypeID() else { return nil }
        return (value as! AXValue)  // swiftlint:disable:this force_cast
    }
}

extension WindowHandle {
    init(_ element: AXUIElement) {
        self.init(AnyHashable(element))
    }

    /// Only the adapters create WindowHandles, always from an AXUIElement.
    var element: AXUIElement {
        id.base as! AXUIElement  // swiftlint:disable:this force_cast
    }
}
```

Why the string literal in `isTrusted`: in Swift 6 mode, referencing the `kAXTrustedCheckOptionPrompt` global fails with "not concurrency-safe because it involves shared mutable state".

```swift
import AppKit
import FlickCore

/// Menu-bar item and Accessibility handling.
@MainActor
final class MenuBarApp: NSObject, NSApplicationDelegate {
    private static let settingsURL = URL(
        string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility")!

    private var statusItem: NSStatusItem?
    private let statusLine = NSMenuItem(title: "", action: nil, keyEquivalent: "")
    private let accessLine = NSMenuItem(title: "", action: nil, keyEquivalent: "")
    private var trusted = false
    private var trustTimer: Timer?

    func applicationDidFinishLaunching(_ notification: Notification) {
        buildMenu()
        trusted = Accessibility.isTrusted(prompt: true)
        if !trusted {
            waitForTrust()
        }
        refreshMenu()
    }

    private func buildMenu() {
        let item = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
        item.button?.image = Self.icon()
        item.button?.toolTip = "Flick"

        let menu = NSMenu()
        menu.autoenablesItems = false
        statusLine.isEnabled = false
        menu.addItem(statusLine)
        menu.addItem(accessLine)
        menu.addItem(.separator())
        menu.addItem(
            NSMenuItem(title: "Quit Flick", action: #selector(NSApplication.terminate(_:)), keyEquivalent: "q"))
        item.menu = menu
        statusItem = item
    }

    private func refreshMenu() {
        statusLine.title = trusted ? "Flick is active" : "Waiting for Accessibility access"
        if trusted {
            accessLine.title = "Accessibility access granted"
            accessLine.isEnabled = false
            accessLine.action = nil
        } else {
            accessLine.title = "Grant Accessibility Access…"
            accessLine.isEnabled = true
            accessLine.target = self
            accessLine.action = #selector(openAccessibilitySettings)
        }
    }

    private func waitForTrust() {
        trustTimer = Timer.scheduledTimer(withTimeInterval: 2, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.checkTrust() }
        }
    }

    private func checkTrust() {
        guard Accessibility.isTrusted(prompt: false) else { return }
        trustTimer?.invalidate()
        trustTimer = nil
        trusted = true
        refreshMenu()
    }

    @objc private func openAccessibilitySettings() {
        NSWorkspace.shared.open(Self.settingsURL)
    }

    /// The menu-bar glyph from the design drawing, as a template image.
    private static func icon() -> NSImage {
        let image = NSImage(size: NSSize(width: 16, height: 12), flipped: true) { _ in
            let path = NSBezierPath()
            path.lineWidth = 1.6
            path.lineCapStyle = .round
            path.lineJoinStyle = .round
            path.move(to: NSPoint(x: 2, y: 10))
            path.line(to: NSPoint(x: 8, y: 4))
            path.move(to: NSPoint(x: 6, y: 11))
            path.line(to: NSPoint(x: 13, y: 4))
            path.move(to: NSPoint(x: 10, y: 2))
            path.line(to: NSPoint(x: 14, y: 2))
            path.line(to: NSPoint(x: 14, y: 6))
            NSColor.black.setStroke()
            path.stroke()
            return true
        }
        image.isTemplate = true
        return image
    }
}
```

```swift
/// Reads and sets window frames through Accessibility.
@MainActor
final class WindowMover: WindowAccess {
    private static let logger = Logger(subsystem: "local.personal.flick", category: "WindowMover")

    func frame(of window: WindowHandle) -> GlobalRect? {
        Accessibility.frame(of: window.element)
    }

    func setFrame(_ frame: GlobalRect, of window: WindowHandle) -> Bool {
        let element = window.element
        // Position, size, position: moving first lets a large window shrink on the target
        // screen; the second move fixes apps that clamp the origin while resizing.
        let moved = Accessibility.setPosition(element, x: frame.x, y: frame.y)
        Accessibility.setSize(element, width: frame.width, height: frame.height)
        Accessibility.setPosition(element, x: frame.x, y: frame.y)
        if !moved {
            Self.logger.warning("Could not move window: AXPosition was rejected")
        }
        return moved
    }
}
```

```swift
import ApplicationServices

/// Finds the standard window whose titlebar zone (top 40 pt) is under a point.
@MainActor
final class TitlebarHitTester: TitlebarProbe {
    static let titlebarHeight: Double = 40

    private let systemWide = AXUIElementCreateSystemWide()
    private let ownPID = ProcessInfo.processInfo.processIdentifier

    func window(atTitlebar point: GlobalPoint) -> WindowHandle? {
        var hit: AXUIElement?
        guard AXUIElementCopyElementAtPosition(systemWide, Float(point.x), Float(point.y), &hit) == .success,
            let hit
        else { return nil }

        var pid: pid_t = 0
        guard AXUIElementGetPid(hit, &pid) == .success, pid != ownPID,
            let window = Self.window(containing: hit),
            Accessibility.string(window, kAXSubroleAttribute) == kAXStandardWindowSubrole,
            let frame = Accessibility.frame(of: window)
        else { return nil }

        let titlebar = GlobalRect(
            x: frame.x, y: frame.y, width: frame.width, height: min(Self.titlebarHeight, frame.height))
        return titlebar.contains(point) ? WindowHandle(window) : nil
    }

    private static func window(containing element: AXUIElement) -> AXUIElement? {
        if Accessibility.string(element, kAXRoleAttribute) == kAXWindowRole {
            return element
        }
        if let window = Accessibility.element(element, kAXWindowAttribute) {
            return window
        }
        var current = element
        for _ in 0..<32 {
            guard let parent = Accessibility.element(current, kAXParentAttribute) else { return nil }
            if Accessibility.string(parent, kAXRoleAttribute) == kAXWindowRole {
                return parent
            }
            current = parent
        }
        return nil
    }
}
```

`Sources/Flick/EventTap.swift`:

```swift
import AppKit
import FlickCore
import os

/// Session event tap for trackpad scroll and gesture events. Hands every event to the
/// recognizer and drops the ones it claims.
@MainActor
final class EventTap {
    private static let logger = Logger(subsystem: "local.personal.flick", category: "EventTap")
    /// CGEventType raw values for gesture events, which have no named case in the SDK.
    private static let gestureTypes: [UInt32] = [29, 30]

    private let recognizer: GestureRecognizer
    private var port: CFMachPort?
    private var source: CFRunLoopSource?

    init(recognizer: GestureRecognizer) {
        self.recognizer = recognizer
    }

    var isRunning: Bool { port != nil }

    /// Returns `false` if the tap could not be created (usually: no Accessibility access).
    func start() -> Bool {
        guard port == nil else { return true }
        var mask = CGEventMask(1) << CGEventType.scrollWheel.rawValue
        for type in Self.gestureTypes {
            mask |= CGEventMask(1) << type
        }
        guard
            let port = CGEvent.tapCreate(
                tap: .cgSessionEventTap, place: .headInsertEventTap, options: .defaultTap,
                eventsOfInterest: mask, callback: eventTapCallback,
                userInfo: Unmanaged.passUnretained(self).toOpaque())
        else {
            Self.logger.error("CGEvent.tapCreate failed")
            return false
        }
        let source = CFMachPortCreateRunLoopSource(nil, port, 0)
        CFRunLoopAddSource(CFRunLoopGetMain(), source, .commonModes)
        CGEvent.tapEnable(tap: port, enable: true)
        self.port = port
        self.source = source
        return true
    }

    /// Returns `true` if the event should be swallowed.
    fileprivate func handle(type: CGEventType, input: InputEvent?) -> Bool {
        if type == .tapDisabledByTimeout || type == .tapDisabledByUserInput {
            Self.logger.warning("Event tap disabled by the system (type \(type.rawValue)), re-enabling")
            if let port { CGEvent.tapEnable(tap: port, enable: true) }
            return false
        }
        guard let input else { return false }
        return recognizer.handle(input) == .swallow
    }
}

private let eventTapCallback: CGEventTapCallBack = { _, type, event, userInfo in
    guard let userInfo else { return Unmanaged.passUnretained(event) }
    let tap = Unmanaged<EventTap>.fromOpaque(userInfo).takeUnretainedValue()
    // Translate before hopping onto the main actor: CGEvent is not Sendable, InputEvent is.
    let input = EventTranslator.input(from: event)
    // The tap's run-loop source is on the main run loop, so this runs on the main thread.
    let swallow = MainActor.assumeIsolated { tap.handle(type: type, input: input) }
    return swallow ? nil : Unmanaged.passUnretained(event)
}

/// Converts CGEvents into FlickCore's InputEvent. Returns `nil` for anything Flick ignores
/// (mouse wheels, other gesture kinds).
enum EventTranslator {
    static func input(from cgEvent: CGEvent) -> InputEvent? {
        guard let event = NSEvent(cgEvent: cgEvent) else { return nil }
        let location = GlobalPoint(x: cgEvent.location.x, y: cgEvent.location.y)
        switch event.type {
        case .scrollWheel:
            guard event.hasPreciseScrollingDeltas else { return nil }
            if let momentum = phase(event.momentumPhase) {
                return .momentum(phase: momentum)
            }
            guard let phase = phase(event.phase) else { return nil }
            return .scroll(
                phase: phase, deltaX: event.scrollingDeltaX, deltaY: event.scrollingDeltaY,
                invertedFromDevice: event.isDirectionInvertedFromDevice, location: location)
        case .magnify:
            guard let phase = phase(event.phase) else { return nil }
            return .magnify(phase: phase, magnification: event.magnification, location: location)
        default:
            return nil
        }
    }

    private static func phase(_ phase: NSEvent.Phase) -> GesturePhase? {
        if phase.contains(.began) { return .began }
        if phase.contains(.changed) { return .changed }
        if phase.contains(.ended) { return .ended }
        if phase.contains(.cancelled) { return .cancelled }
        if phase.contains(.mayBegin) { return .mayBegin }
        return nil
    }
}
```

Two Swift 6 details this code already handles. (1) The C callback translates the `CGEvent` into the `Sendable` `InputEvent` *before* `MainActor.assumeIsolated`; passing the `CGEvent` itself in fails with "sending 'event' risks causing data races". (2) Gesture event types 29/30 have no named `CGEventType` case, so the mask is built from raw values.

```swift
import AppKit
import FlickCore

/// Menu-bar item, Accessibility handling and wiring of the whole app.
@MainActor
final class MenuBarApp: NSObject, NSApplicationDelegate {
    private static let settingsURL = URL(
        string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility")!

    private var statusItem: NSStatusItem?
    private let statusLine = NSMenuItem(title: "", action: nil, keyEquivalent: "")
    private let accessLine = NSMenuItem(title: "", action: nil, keyEquivalent: "")
    private let pauseItem = NSMenuItem(title: "Pause gestures", action: nil, keyEquivalent: "")
    private var recognizer: GestureRecognizer?
    private var tap: EventTap?
    private var trustTimer: Timer?

    func applicationDidFinishLaunching(_ notification: Notification) {
        let controller = FlickController(windows: WindowMover(), screens: ScreenAdapter(), preview: PreviewOverlay())
        let recognizer = GestureRecognizer(probe: TitlebarHitTester()) { controller.handle($0) }
        self.recognizer = recognizer
        tap = EventTap(recognizer: recognizer)
        buildMenu()

        if Accessibility.isTrusted(prompt: true) {
            startTap()
        } else {
            waitForTrust()
        }
        refreshMenu()
    }

    private func buildMenu() {
        let item = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
        item.button?.image = Self.icon()
        item.button?.toolTip = "Flick"

        let menu = NSMenu()
        menu.autoenablesItems = false
        statusLine.isEnabled = false
        menu.addItem(statusLine)
        menu.addItem(accessLine)
        menu.addItem(.separator())
        pauseItem.target = self
        pauseItem.action = #selector(togglePause)
        menu.addItem(pauseItem)
        menu.addItem(.separator())
        menu.addItem(
            NSMenuItem(title: "Quit Flick", action: #selector(NSApplication.terminate(_:)), keyEquivalent: "q"))
        item.menu = menu
        statusItem = item
    }

    private func refreshMenu() {
        let trusted = tap?.isRunning ?? false
        let paused = recognizer?.isPaused ?? false
        if !trusted {
            statusLine.title = "Waiting for Accessibility access"
        } else {
            statusLine.title = paused ? "Flick is paused" : "Flick is active"
        }
        if trusted {
            accessLine.title = "Accessibility access granted"
            accessLine.isEnabled = false
            accessLine.action = nil
        } else {
            accessLine.title = "Grant Accessibility Access…"
            accessLine.isEnabled = true
            accessLine.target = self
            accessLine.action = #selector(openAccessibilitySettings)
        }
        pauseItem.state = paused ? .on : .off
        pauseItem.isEnabled = trusted
    }

    private func startTap() {
        _ = tap?.start()
        refreshMenu()
    }

    private func waitForTrust() {
        trustTimer = Timer.scheduledTimer(withTimeInterval: 2, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.checkTrust() }
        }
    }

    private func checkTrust() {
        guard Accessibility.isTrusted(prompt: false) else { return }
        trustTimer?.invalidate()
        trustTimer = nil
        startTap()
    }

    @objc private func togglePause() {
        recognizer?.isPaused.toggle()
        refreshMenu()
    }

    @objc private func openAccessibilitySettings() {
        NSWorkspace.shared.open(Self.settingsURL)
    }

    /// The menu-bar glyph from the design drawing, as a template image.
    private static func icon() -> NSImage {
        let image = NSImage(size: NSSize(width: 16, height: 12), flipped: true) { _ in
            let path = NSBezierPath()
            path.lineWidth = 1.6
            path.lineCapStyle = .round
            path.lineJoinStyle = .round
            path.move(to: NSPoint(x: 2, y: 10))
            path.line(to: NSPoint(x: 8, y: 4))
            path.move(to: NSPoint(x: 6, y: 11))
            path.line(to: NSPoint(x: 13, y: 4))
            path.move(to: NSPoint(x: 10, y: 2))
            path.line(to: NSPoint(x: 14, y: 2))
            path.line(to: NSPoint(x: 14, y: 6))
            NSColor.black.setStroke()
            path.stroke()
            return true
        }
        image.isTemplate = true
        return image
    }
}
```
